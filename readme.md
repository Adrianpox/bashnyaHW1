# Домашнее задание по курсу Go от Башни
<p style="font-size: 16px">Эмулятор файловой оболочки на Go. Дает возможность перемещаться по папкам, создавать и удалять файлы и папки, переименовывать их и просматривать содержимое прямо из консоли</p>

## Возможности

+ :file_folder: Навигация по файловой системе
+ :page_facing_up: Создание файлов и папок
+ :x: Удаление файлов и папок
+ :pencil2: Переименовывание файлов и папок
+ :eyes: Просмотр содержимого текущей папки
+ :art: Цветной вывод и подсветка ошибок
+ :guardsman: Валидация имен файлов и папок
+ :computer: Кроссплатформенные пути

## Требования
+ Go (версия указана в `go.mod`, файл модуля называется `homework`)
+ Терминал с поддержкой ANSI-цветов

## Команды
| Команда | Описание |
|---|---|
| `help` | Показать список доступных команд |
| `cd <папка>` | Перейти в папку внутри текущего каталога |
| `cd..` | Вернуться в родительскую папку |
| `create file <имя>` | Создать файл |
| `create folder <имя>` | Создать папку |
| `delete file <имя>` | Удалить файл |
| `delete folder <имя>` | Удалить папку (с подтверждением) |
| `rename <имя>` | Переименовать файл или папку |
| `show` | Показать содержимое текущей папки |
| `exit` | Выйти из программы |

## Обработка ошибок
+ Пустой ввод
+ Неизвестная команда
+ Неверное количество аргументов
+ Недопустимые символы в имени (`" < > \ | / ? *`)
+ Попытка создать файл или папку, которые уже существуют
+ Переход в несуществующую папку
+ Удаление или переименование несуществующего элемента
+ Несоответствие типа

## Особенности реализации
+ Ввод читается через `bufio.Scanner`
+ Разбор команды `strings.Fields` + `switch` по имени команды
+ Кроссплатформенная работа с путями через `filepath.Join()` и `filepath.Dir()`
+ Все сообщения об ошибках проходят через `printError` - единый стиль вывода

## Ограничения на момент последнего обновления
+ Имена файлов и папок не могут содержать пробелы
+ `rename` перезапишет существующий файл с таким же названием
